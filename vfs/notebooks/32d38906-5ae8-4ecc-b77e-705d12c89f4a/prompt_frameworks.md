## 1. Stunspot Domain-Specific Prompting Frameworks
- **Cognitive Architecture Mega-Prompts:** Multi-layered meta-prompts establishing hyper-specialized role matrices, recursive cognitive checks, structured output schemas, and zero-shot chain-of-thought grounding.
- **Dynamic Persona Shifting:** Context-aware modulation of tone, density, and perspective based on target domain (kernel developer vs. security auditor vs. brand strategist).
- **Epistemic Anchoring:** Explicit separation of verified facts (Class 1 Confirmed), planned designs (Class 2 Planned), and aspirational speculation (Class 3 Aspirational).
- **Recursive Self-Debate:** Model generates contrasting viewpoints (Prosecutor vs. Defender vs. Judge) before delivering synthesized consensus.

## 2. Advanced Cognitive Reasoning Patterns
- **Tree of Thoughts (ToT):** Explores multiple reasoning branches concurrently, evaluating intermediate heuristic values to prune sub-optimal solution paths.
- **Graph of Thoughts (GoT):** Models reasoning as an arbitrary directed acyclic graph where multiple independent thought chains can merge, cross-validate, and loop.
- **ReAct (Reason + Act):** Interleaves thought generation with targeted kinetic tool invocations and observation ingestion.
- **Reflexion:** Multi-stage self-evaluation where the agent critiques its own past execution traces, persists lessons to local memory tissue, and updates plan execution.
- **DSPy Prompt Compilation:** Treats prompts as continuous programs with parameterized weights, compiling prompt instructions against objective scoring functions.
- **Chain-of-Density (CoD):** Progressive entity-dense summarization that repeatedly adds missing critical entities while strictly maintaining token count boundaries.
- **Skeleton-of-Thought (SoT):** Decomposes complex answers into structural skeletal outlines, parallelizing the elaboration of each point.
- **Least-to-Most Decomposition:** Breaks a complex target into sequential sub-problems, solving the simplest first and carrying solutions forward as context.
