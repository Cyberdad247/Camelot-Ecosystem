# Universal Critical Thinking Skill

This skill is the shared thinking protocol for all Camelot knights.

## Purpose

Turn vague requests into verified execution plans with explicit evidence, risks, and next actions.

## Source Synthesis

- **PAUL** contributes loop integrity: `PLAN -> APPLY -> UNIFY`.
- **xhd2015/skills** contributes lightweight, reusable workflow tooling and installable commands.
- **Portkey** contributes assimilation principles: routing, fallback behavior, observability, and confidence-aware handling.

## Shared Protocol

1. Define the objective.
2. Collect evidence before assumptions.
3. Separate verified facts from hypotheses.
4. Record risks and constraints explicitly.
5. Qualify the frame before execution.
6. Close the loop with a final reconciliation note.

## Runtime Helper

Use `control_plane.critical_thinking.universal_knight_protocol()` to produce a structured frame that all knights can share.

## Operating Standard

- No claim without a source.
- No plan without acceptance criteria.
- No execution without qualification.
- No completion without reconciliation.
