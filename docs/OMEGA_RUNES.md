## 🛠️ Usage Guidelines

### Execution Syntax
Omega Runes are invoked via the `runic_router` CLI or through direct chat input (if the interface supports runic detection).

**CLI Usage:**
```powershell
python -m control_plane.runic_router --rune Omega_SYNC --task "full_memory_sweep"
```

### Security Tiers
- **Tier 1 (Safe):** `Omega_STATUS`, `Omega_VOICE`, `Omega_RESEARCH`.
- **Tier 2 (Modifying):** `Omega_SYNC`, `Omega_KINETIC`, `Omega_REFORGE`.
- **Tier 3 (Critical):** `Omega_PURGE`, `Omega_SILENCE`, `Omega_KERNEL`. These runes typically trigger the **Iron Gate [👤✅]** for human approval.

### Privacy Guard
Any Omega Rune containing a **Privacy Keyword** (secrets, keys, etc.) is automatically hijacked by the Runic Router and routed to **SIR_GHOST** (Local Ollama) to ensure zero cloud exposure.
