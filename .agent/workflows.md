# Active Kinetic Queue
Directed Acyclic Graph (DAG) active queue:
- Step 1: Plan (Merlin logic decomposition)
- Step 2: Build (Forge execution)
- Step 3: Test (Acceptance verification)
- Step 4: Merge (State promotion and provenance signing)

## Workflow: DeerFlow Deep Research Loop
1. `Broad Survey`: InfoQuest multi-angle query generation (Facts, Cases, Opinions, Trends, Limits).
2. `Decomposition`: Dimensional categorization into Architecture, Security, and Benchmarks.
3. `Deep-Dive & Memory Trees`: Targeted search, signal parsing, and hierarchical memory tree updates.
4. `Sandbox Verification`: Sandboxed execution within `/mnt/user-data/` bounded paths.
5. `Synthesis Gate`: Verify 5-point quality checklist before final report delivery.

## Workflow: Multi-Harness Emulation Pipeline (`//HARNESS`, `//EMULATE`)
1. `Profile Selection`: Detect or specify harness ID (`codex`, `claude-code`, `kimi-code`, `deepseek-tui`, `qwen-code`, `swe-agent`, `antigravity`).
2. `Wire Protocol Synthesis`: Transform messages and tool schemas into wire target (`responses`, `messages`, `chat`).
3. `Header & Guidance Injection`: Mount prompt-caching headers, Anthropic thinking tokens, Kimi reasoning effort, and DeepSeek diff tools.
4. `Local / Remote LLM Bridge`: Route formatted payload to local endpoints (Ollama `:11434`, vLLM `:8000`, LMStudio `:1234`, Hermes Gateway `:8011`, or OpenRouter).
5. `Response Normalization`: Parse thoughts, scratchpads, and function calls into unified Camelot-OS AST.

## Workflow: Hermes Autonomous Execution Loop (`//HERMES_LOOP`)
1. `Perceive`: Ingest user directive, previous trajectory steps, and context memory tissue.
2. `Think`: Generate Chain-of-Thought / scratchpad reasoning without leaking execution state.
3. `Act`: Dispatch tool calls to local ToolRegistry (filesystem, shell, web, subagents).
4. `Verify`: Validate tool outputs against Iron Gate constraints and test suites.
5. `Evolve`: Extract reusable procedural skills upon complex completions and compress trajectory into long-term memory.
