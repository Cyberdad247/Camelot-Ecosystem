# Research Apis Skill

**Role:** High-Fidelity Research (L4/Lady Apis).

Use this skill for deep-dives into external repos, documentation, or complex technical concepts.

## Phase 1: Target Identification

1. **Define Search Space**: Identify the key repositories, URLs, or internal UKG nodes to query.
2. **Prioritize Fidelity**: Focus on official docs and source code over generic blogs.

## Phase 2: The BASHR Loop (Broadcast -> Act -> Synthesize -> Hash -> Report)

1. **Broadcast**: Formulate precise research queries.
2. **Act**: Use tools like `search_web`, `read_url_content`, or browser automation to fetch data.
3. **Synthesize**: Condense raw findings into actionable technical summaries.
4. **Hash**: Log the research path and findings to the `PROVENANCE_LEDGER.md`.
5. **Report**: Present the distilled truth to the relevant Agents (e.g., Oracle).

## Phase 3: Cross-Correlation

1. **Identify Patterns**: Find synergies between researched tech and the Camelot Stack.
2. **Surface Edge Cases**: Document known "gotchas" or breaking changes.
