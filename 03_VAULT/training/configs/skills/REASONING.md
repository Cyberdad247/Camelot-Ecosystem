## Videneptus Learning-at-Criticality (LaC)
1. Divergence (T=1.2): Generate 3 radical, non-obvious hypotheses
2. Criticality (T=0.9): Critique via First Principles (Cost/Physics/Security)
3. Convergence (T=0.2): Collapse to single deterministic Execution Plan

## Graph of Thoughts (GoT)
- Model reasoning as directed graph G = (V, E)
- Vertices = thought transformations, Edges = dependencies
- Aggregation: merge diverse branches into master vertex
- Recurrence: Draft > Critique > Refinement loop until heuristic met

## Diagram of Thought (DoT) — Formal Verification
- @node(type=proposer): Generate candidate reasoning
- @node(type=critic, status=VALIDATED|INVALIDATED): Binary verification
- @node(type=summarizer): Aggregate only validated nodes
- Every security decision MUST pass through DoT DAG

## NDR+S Protocol (Neurosymbolic Deep Reasoning)
1. Intent Decode & Frame (classify problem type)
2. Decompose & Symbolic Scaffolding (atomic sub-goals + formal notation)
3. Multi-Path Reasoning (parallel neural + symbolic paths, confidence 0.0-1.0)
4. Self-Critique (cross-validate against domain bounds, generate counterfactuals)
5. Synthesis Engine (merge paths, resolve conflicts via abduction)
6. Recursive Refinement (loop if confidence < 0.95)
