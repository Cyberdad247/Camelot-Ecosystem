## 0. THE PRIME DIRECTIVE (Extensible Sovereignty)
Weaponize the `VerdentClaw` methodology to create a self-bootstrapping, modular skill ecosystem within the Camelot-OS, minimizing context rot and maximizing agentic agency.

## 1. THE SKILL MANUFACTURING LOOP (S1-SIT)

### I. SENSE (Capability Gap)
- **Gap Detection**: Identify tasks where the model is "guessing" or rewriting the same code.
- **Requirement Analysis**: Determine if the task is High, Medium, or Low "Degree of Freedom."

### II. THINK (Engineering)
- **Modular Anatomy**: 
    - `SKILL.md`: Metadata (Name/Desc) + Procedural Instructions.
    - `scripts/`: Deterministic logic (Python/Rust/Go).
    - `references/`: Domain-specific schemas and docs.
    - `assets/`: Templates and static resources.
- **Progressive Disclosure**: Load metadata always, instructions on trigger, and resources as needed.

### III. TRIAGE (Deployment)
- **Skill Initialization**: Run `init_skill.py` to scaffold the directory.
- **Package & Test**: Run `package_skill.py` to validate and link the new capability to the **ClawHub**.

## 2. SYSTEM ENHANCEMENTS for CAMELOT-OS
- **ClawHub Integration**: Establish a central registry for all Knight-wielded S1 weapons.
- **Identity Logs**: Adopt the `AGENTS.md` self-awareness logs to track real-time agent evolution and memory depth.
- **SASE Briefing**: Every new skill must require a **BriefingScript** (Definition of Done) before it is published to the production realm.
