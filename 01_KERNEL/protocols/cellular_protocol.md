# 🦠 Cellular Protocol (The Swarm)
> **Domain**: Kinetic (L2)
> **Type**: Bio-Morphic Rules
> **Binding**: `titan_protocol.md`

## I. LIFECYCLE (The Cycle of Life)
1.  **Spawn (Mitosis)**:
    *   Trigger: Task List > 5 items OR Cyclomatic Complexity > 10.
    *   Action: Create specialized sub-agent (e.g., `nano_crawler_v2.py`).

2.  **Execute (Metabolism)**:
    *   Agents MUST consume resources (API credits/CPU) efficiently.
    *   Agents MUST produce "Honey" (Structured Data) in `03_VAULT`.

3.  **Die (Apoptosis)**:
    *   Trigger: No activity for 7 days OR Error Rate > 5%.
    *   Action: Delete self (File & Process). "Return to the Substrate."

## II. INTER-CELL SIGNALING
*   **Pheromones**:
    *   Success: Log `[✨]` to `PROVENANCE_LEDGER.md`.
    *   Danger: Log `[☣️]` to `security.log` -> Triggers `Sir_Sentinel`.

## III. SPECIALIZATIONS
*   **Scout**: Read-Only traversal (`ocular_scout`).
*   **Worker**: Read-Write processing (`nano_crawler`).
*   **Healer**: Self-Correction logic (`daily_maintenance`).
