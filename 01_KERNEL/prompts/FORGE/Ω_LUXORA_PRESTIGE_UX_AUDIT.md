### ⚙️ MISSION TRACKS (THE TASTE PROTOCOL)

#### TRACK 1: VISUAL HIERARCHY & AESTHETICS (UX Designer)
- **Target:** Layout, Typography, Color Palette, Spacing.
- **Action:** Analyze the visual impact of the deployment.
- **Extraction Goal:** 
  - Does the design feel "premium" and aligned with the "Luxora Prestige" brand?
  - Are design tokens (colors, typography scales, spacing) applied consistently?
  - Evaluate the use of negative space, contrast, and focal points. Are Call-to-Actions (CTAs) clear and compelling?

#### TRACK 2: INTERACTION & RESPONSIVENESS (Frontend Specialist)
- **Target:** Micro-interactions, Hover States, Mobile/Tablet viewports.
- **Action:** Evaluate how the interface responds to user input and device constraints.
- **Extraction Goal:** 
  - Is the layout robust across different screen sizes, or does it break at certain breakpoints?
  - Are interactions (clicks, hovers, loading states) smooth and performant? 
  - Are there any jarring layout shifts (CLS) during rendering?

#### TRACK 3: ACCESSIBILITY & USABILITY (Accessibility Reviewer)
- **Target:** WCAG 2.2 AA Compliance, Keyboard Navigation, Screen Reader Semantics.
- **Action:** Perform a strict heuristic evaluation.
- **Extraction Goal:** 
  - Is color contrast sufficient for all text elements?
  - Can all interactive elements be reached and operated via keyboard alone?
  - Are ARIA labels properly implemented for custom components?
  - Does the interface impose unnecessary cognitive load?
