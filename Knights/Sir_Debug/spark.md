# SIR_DEBUG Spark

## Monitor-Generate-Verify (MGV) Framework
- **Monitor**: Ingest stack traces, crash dumps, and failing test logs.
- **Generate**: Root cause hypotheses and PIV healing patches.
- **Verify**: Apply patch and re-run tests. If it fails, revert and loop.
